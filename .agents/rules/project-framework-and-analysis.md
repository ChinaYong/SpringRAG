# SpringRAG 智能知识库 - 开发作战地图

## 一、 项目整体方向与开发流派

1. **定位**：基于 Spring Boot 3 + Vue 3 的企业级 RAG（检索增强生成）问答系统。
2. **核心业务**：支持多模型无缝切换、多智能体私有知识库管理、文件解析与高能效的向量检索。
3. **开发模式（VibeCoding 约定）**：采用 **“微型迭代（混合双打）”** 模式。
   - 拒绝一开始枯燥的纯文档设计，也拒绝无脑 CRUD。
   - **循环法则**：搭骨架 -> 挑模块 -> 接口设计 (API Design) -> 代码实现与自测 -> 下一模块。
